# Stochastic Epidemic Modeling with the SIRD Model

A computational study of epidemic dynamics using the **Susceptible–Infected–Recovered–Deceased (SIRD)** model. The project compares deterministic differential-equation solutions with stochastic epidemic trajectories generated by the **Gillespie stochastic simulation algorithm (SSA)**.

**Authors:** Martina Balsamello and Matteo Zabban — collaborative academic project.

## Overview

Deterministic compartmental models describe a single epidemic trajectory for a given parameter set, whereas stochastic models account for random infection, recovery, and death events. This project investigates how those two perspectives differ, including outbreak variability, epidemic peaks, and early fade-out.

## Methods and analysis

The notebook covers:

- **Deterministic SIRD model:** numerical integration of the compartmental ordinary differential equations.
- **Stochastic SIRD model:** event-driven simulation using Gillespie's direct method.
- **Simulation ensembles:** repeated stochastic runs and summary statistics to characterize uncertainty.
- **Deterministic vs. stochastic comparison:** infection trajectories, peak size and timing, and early epidemic extinction.
- **Parameter sensitivity:** effects of infection rate (β), population size (N), and mortality rate (μ), including a joint β–μ analysis.
- **Time-dependent transmission:** simulated interventions that change the infection rate β(t).

## Interpretation and limitations

The SIRD model assumes a closed, well-mixed population and simplified disease transitions. The simulations are intended to illustrate mathematical and stochastic epidemic dynamics; they are **not calibrated forecasts** or medical guidance. Results from stochastic runs can vary with the random seed and simulation settings.
